# Brand font

The Glimmr wordmark is set in **Akira Expanded** (Typologic). It is a commercial font, so it is not bundled here.

To use it, place a licensed copy in this folder with one of these names:

- `akira-expanded.woff2` (preferred)
- `akira-expanded.otf`
- `akira-expanded.ttf`

If the font is installed on the system it is used automatically. Without it, the wordmark falls back to
Archivo at its widest and heaviest setting.
